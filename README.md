A multi-agent LLM system that uses specialized agents to **analyze, solve, review, and synthesize** responses.

**Architecture:**

```text
User Problem
     ↓
Researcher
     ↓
Coder
     ↓
Critic
     ↓
CEO / Final Synthesizer
     ↓
Final Response
````

**Highlights:**

* Built a four-agent system using the **Gemini API**
* Implemented specialized **Researcher, Coder, Critic, and CEO** agents
* Designed agent orchestration and inter-agent communication
* Implemented iterative critique and response synthesis
* Deployed on **Hugging Face Spaces**
